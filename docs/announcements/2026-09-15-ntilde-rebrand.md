# NovaTerminal is now Ntilde

Same terminal, new name. Release [v0.10.0](https://github.com/benyblack/ntilde/releases/tag/v0.10.0)
renames the product, the binaries, the packages and the command (`ntilde`, was `nova`). Your
settings move over automatically on first launch; saved passwords need re-entering once.

If you installed NovaTerminal with the Windows installer or the macOS package, it updates itself
into Ntilde on its next update check, in place, shortcuts included. The portable zip has no
updater: download Ntilde and delete the old copy. Debian and Arch packages supersede
`novaterminal` automatically. Full details and every install path are in the README section
"Coming from NovaTerminal".

Why "Ntilde"? The tilde is the shell's home, and the name is short enough to type.
