## Identity finding

Before correction, the shell reported `TERM_PROGRAM=Ntilde` while inheriting
`TERM_PROGRAM_VERSION=3.7.4` and `__CFBundleIdentifier=com.googlecode.iterm2`.
The collector prioritizes the bundle ID and labeled the first run iTerm2 3.7.6.
That run is retained separately under
`artifacts/terminfo/baseline-2026-10-30/`; it is not an iTerm2 measurement and must
not be submitted as one.

The repeat removed the stale bundle hint and supplied the sidecar version
explicitly. Its outcome counts matched the first run. The runner now records
these adjustments and rejects an unexpected collector identity. A future
PTY-environment change could set Ntilde's own version and clear inherited product
hints at launch; no runtime behavior was changed for this pilot.

## Follow-up

Rerun against a freshly identified current build before investigating the
no-response observations as regressions. Broader behavioral coverage needs an
upstream adapter that can verify ownership of a disposable Ntilde instance;
an ordinary inline invocation cannot establish it. Keep deterministic Ntilde
tests as the authority for parser and renderer behavior.

A subsequent [local owned macOS adapter run](2026-10-30-macos-owned.md) implements
process/PTY ownership and reduces these ownership refusals. Its collector
