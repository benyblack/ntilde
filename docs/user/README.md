# Ntilde user guide

Ntilde is a cross-platform terminal emulator built for correctness, performance and predictability,
with persistent sessions, a built-in SSH client and opt-in access for AI agents.

Shortcuts in this guide are the Windows and Linux defaults. On macOS most use `Cmd` in place of
`Ctrl`; [Keyboard shortcuts](shortcuts.md#macos) lists the exceptions.

## Start here

- [Installing and updating](install.md): Windows, macOS and Linux packages, first run, updates,
  uninstalling, and moving from NovaTerminal.
- [Keyboard shortcuts, the command palette and the mouse](shortcuts.md): every default shortcut,
  how to rebind them, and every palette command.
